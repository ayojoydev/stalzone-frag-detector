# Как внести вклад в SZFD

Спасибо за желание улучшить проект. Перед началом работы создайте отдельную ветку
от актуальной `main` и постарайтесь держать Pull Request посвящённым одной задаче.

## Подготовка окружения

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --editable ".[dev]"
```

## Проверка изменений

Перед отправкой PR запустите тесты:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Изменения распознавания желательно проверять как минимум на одном настоящем видео
или скриншоте. Для новых параметров CLI и публичного Python API добавляйте тесты.
Не включайте в коммит исходные игровые записи, готовые клипы, виртуальное окружение
и результаты сборки.

## Pull Request

В описании укажите:

- какую проблему решает изменение;
- как меняется поведение пользователя;
- какие команды и сценарии были проверены;
- есть ли изменения формата CSV, CLI или Python API.

Сохраняйте обратную совместимость документированных команд и импортов. Если она
невозможна, явно отметьте это в описании PR. Выпуск релиза и создание тега выполняет
владелец репозитория после проверки и слияния изменений.
