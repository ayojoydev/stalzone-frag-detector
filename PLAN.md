# План: Stalzone Frag Detector

## Цель

Сделать локальный CLI-инструмент, который просматривает запись матча Stalzone,
находит нижнюю плашку убийства по значку черепа, сохраняет таймкоды и по желанию
вырезает клипы вокруг событий через FFmpeg.

## Этапы

1. Подготовить эталон значка черепа из предоставленного скриншота.
2. Реализовать поиск шаблона в настраиваемой нижней центральной области кадра.
3. Проверять каждый N-й кадр (по умолчанию каждый 15-й).
4. Объединять повторные срабатывания одной секундной плашки в одно событие.
5. Сохранять результаты в TXT, CSV и JSON.
6. Добавить отладочные кадры с отмеченным местом срабатывания.
7. Добавить нарезку клипов до и после события:
   - `copy`: без пережатия, с границами по ближайшим ключевым кадрам;
   - `exact`: точные границы с перекодированием.
8. Проверить детектор на предоставленном скриншоте и покрыть чистую логику тестами.
9. Описать установку, запуск и настройку порога/области поиска.

## Критерии готовности первой версии

- Скриншот-пример уверенно определяется как плашка убийства.
- Один показ плашки не создаёт несколько таймкодов.
- Инструмент работает с произвольной частотой кадров и сообщает прогресс.
- Нарезка отключена по умолчанию и включается флагом `--clips`.
- Исходное видео никогда не изменяется.
- Все параметры, влияющие на точность, доступны через CLI.

## Ограничения первой версии

- Событие определяется по значку и плашке, без распознавания ника.
- Очень быстрые последовательные убийства, при которых плашка не исчезает между
  обновлениями, могут быть объединены в одно событие.
- Для нарезки без пережатия точность начала клипа зависит от ключевых кадров видео.
- Порог может потребовать разовой настройки для другого масштаба интерфейса,
  цветокоррекции или нестандартного разрешения записи.
